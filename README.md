## Development

```bash
npm install
npm run dev
```

Storybook:

```bash
npm run dev:storybook
```

Tests:

```bash
npm test
npm run test:coverage
```

## Deployment

Preview deploys run automatically on push. Production deploys from `main` are manual.

```bash
npm run build
```
